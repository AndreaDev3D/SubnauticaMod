# AD3D StorageSolution Mod (Below Zero)

The Below Zero edition of AD3D StorageSolution. Brings the same set of buildable storage containers to Subnautica: Below Zero, so your snow-bound bases stay organised.

## Features

- New storage containers buildable from the Habitat Builder menu.
- Fits alongside the game's existing storage and inventory UI.

## Installation

1. Install **BepInEx** and **Nautilus** for Below Zero.
2. Download `AD3D_StorageSolution.BZ.zip` from the [releases](../../releases) page.
3. Unzip into your Below Zero `BepInEx/plugins` folder.
4. Launch the game — the new storage items appear in the Habitat Builder.

## Compatibility

Built against current Nautilus for Below Zero. For the original game, use [AD3D StorageSolution Mod (Subnautica)](../Subnautica.SN). See the manifest for the exact dependency pins used per release.
