# AD3D StorageSolution Mod (Subnautica)

Adds a set of buildable storage solutions to Subnautica's Habitat Builder — extra lockers and containers to keep your base organised without papering every wall with the stock locker.

## Features

- New storage containers buildable from the Habitat Builder menu.
- Fits alongside the game's existing storage and inventory UI.

## Installation

1. Install **BepInEx** and **Nautilus** if you haven't already.
2. Download `AD3D_StorageSolution.SN.zip` from the [releases](../../releases) page.
3. Unzip into your Subnautica `BepInEx/plugins` folder.
4. Launch the game — the new storage items appear in the Habitat Builder.

## Compatibility

Built against current Nautilus for Subnautica (the original game). For Below Zero, use [AD3D StorageSolution Mod (Below Zero)](../Subnautica.BZ). See the manifest for the exact dependency pins used per release.
