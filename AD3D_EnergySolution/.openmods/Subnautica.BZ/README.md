# AD3D EnergySolution Mod (Below Zero)

The Below Zero edition of AD3D EnergySolution. Brings the same buildable energy kit — a depth-scaling **Deep Engine** generator and a **Wind Turbine** — to Subnautica: Below Zero, so your frozen outposts can stay powered far from the surface.

## Features

- **Deep Engine** — a generator whose output scales with depth, for deep BZ bases.
- **Wind Turbine** — surface/shallow power that complements solar.
- Buildable straight from the Habitat Builder menu, no console commands.

## Installation

1. Install **BepInEx** and **Nautilus** for Below Zero.
2. Download `AD3D_EnergySolution.BZ.zip` from the [releases](../../releases) page.
3. Unzip into your Below Zero `BepInEx/plugins` folder.
4. Launch the game — the new generators appear in the Habitat Builder.

## Compatibility

Built against current Nautilus for Below Zero. For the original game, use [AD3D EnergySolution Mod (Subnautica)](../Subnautica.SN). See the manifest for the exact dependency pins used per release.
