# AD3D EnergySolution Mod (Subnautica)

Adds a set of buildable energy solutions to Subnautica's Habitat Builder, so you can power deeper, larger bases without leaning on a wall of solar panels. Includes a depth-scaling **Deep Engine** generator and a **Wind Turbine** for surface and shallow setups.

## Features

- **Deep Engine** — a generator whose output scales with depth, for bases the sun never reaches.
- **Wind Turbine** — surface/shallow power that complements solar.
- Buildable straight from the Habitat Builder menu, no console commands.

## Installation

1. Install **BepInEx** and **Nautilus** if you haven't already.
2. Download `AD3D_EnergySolution.SN.zip` from the [releases](../../releases) page.
3. Unzip into your Subnautica `BepInEx/plugins` folder.
4. Launch the game — the new generators appear in the Habitat Builder.

## Compatibility

Built against current Nautilus for Subnautica (the original game). For Below Zero, use [AD3D EnergySolution Mod (Below Zero)](../Subnautica.BZ). See the manifest for the exact dependency pins used per release.
