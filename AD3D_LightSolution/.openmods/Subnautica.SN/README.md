# AD3D Light Solution (Subnautica)

A complete lighting kit for your Subnautica bases and outposts. Adds buildable indoor and outdoor lights plus a centralised **Light Switch** that lets you toggle every fixture in range and dial in its **color** and **brightness** on the fly — no more uniform white glow across every habitat.

## Features

- Indoor and outdoor light props that snap to base modules and exterior terrain.
- A `light_switch` buildable that controls every light it can reach.
- Adjustable color picker and brightness slider directly from the switch UI.
- Designed for Subnautica (the original game). For Below Zero, use [AD3D Light Solution (Below Zero)](../Subnautica.BZ).

## Installation

1. Install **BepInEx** and **Nautilus** if you haven't already.
2. Download `AD3D_LightSolution.SN.zip` from the [releases](../../releases) page.
3. Unzip into your Subnautica `BepInEx/plugins` folder. The final path should look like:
   ```
   Subnautica/BepInEx/plugins/AD3D_LightSolution.SN/
   ```
4. Launch the game — the lights and switch appear in the Habitat Builder menu.

## Usage

Place a `light_switch` inside any base or attached to an exterior surface. Any AD3D light built within its range is automatically registered. Open the switch panel to toggle the group, change color, or adjust brightness.

## Compatibility

Designed as an add-on for the AD3D base mod (modId 26 on OpenMods) and pairs cleanly with Nautilus-based builds. See the manifest for exact release-pin requirements.
